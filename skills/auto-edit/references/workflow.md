# 共用素材與 Premiere 工作規格

規則適用全部實拍剪輯案件。這是素材、版本與Premiere交換的通用工作契約；細目索引見 `common.json`。

## 收件及前置整理

分類確認後建立唯一 case_id、當集來源白名單與授權階段。以 workspace 或具名 media root 加相對路徑保存位置；每個來源記角色、版號、大小與 SHA256。舊集參考只能當 reference，不是本集可剪素材。原片、人工 XML／SRT、基準稿唯讀；產物另存版本。大型原片留使用者媒體儲存，知識倉庫只放規則及精簡證據索引。

先讀最新人工版與既有字幕，再判斷尚缺證據。畫面取樣記實際時間／幀，選鏡至少看入點、中段、尾部和動作連續性；縮圖、運動分數、ASR 與波形不能單獨判 NG、人物身份或已完整觀看。字幕空白不是靜音。開始、中間、結尾比對音畫地標，固定偏移與漂移分開處理。混音可用於單主角；多人精準時間需依真實講者／主聲源判斷，不複製混音假裝分軌。

## 通用口語精簡（C11–C14）

- 沒有語意功能的思考空氣與等待直接刪除；說話者明確呈現驚訝、傻眼等反應時，可保留停頓作節奏與效果。
- 去除不承擔語意或銜接功能的口語贅詞，例如「就是、其實、然後」。不能只做字串刪除；剪後仍須檢查語法、原意、呼吸與聲音銜接。
- 重複內容只保留最適合的一版。若不同次重講各有較好的開頭與結尾，可跨版本拼接，形成完整自然且不改變原意的一段；逐段記錄來源映射。
- 製作人喊卡、錄製中場與純拍攝協調片段預設刪除；只有使用者另有花絮或效果需求時才保留。

## 交付位置（C08）

所有交付物，包括字幕、XML、索引、報告與附件，先確認使用者指定的客戶及當集專案目的地。品牌名稱或工具工作目錄不足以判定專案。

- 使用已確認且存在、掛載可用、可寫的客戶專案位置；沿用用途相符的既有交付子目錄。使用者本次明確指定位置優先，位置已確認便直接使用。
- 缺少、無法唯一判定或不可寫時，在存放交付檔前回報具體缺口；不回退到工具目錄、桌面或其他案件，不在離線掛載點建立假的專案目錄。
- 內部暫存僅供處理，交付前將必要檔案存入確認的目的地，核對大小、可讀性與 hash，再提供實際客戶路徑。無明確覆寫授權時另存版本。
- 此規則不批次搬移舊案，case/job 與舊證據繼續原有保存制度。

## 分階段完成使用者要求

|階段|輸入依賴|交付與驗證|
|---|---|---|
|evidence|確認分類與本集白名單|來源清單、序列資訊、同步、聲畫取樣紀錄|
|classification/selects|可讀本集來源|分類／精選索引、半開來源 IN/OUT、取捨理由及未決項|
|roughcut|受支援 XML＋同版文字／音訊|全長保留、只切割標色；照粗剪工具驗證|
|assembly|最新主軸＋已驗證可用來源|另存精剪或 B-roll 覆蓋軌、每段來源映射|
|text|同版成片／時間軸＋文字證據|對話、編輯旁白、標題各自辨識角色，不混作逐字稿|
|delivery|實際產物|hash、結構／聲畫／Premiere 匯入分別列結果|
|learning|使用者指定人工版與學習要求|逐項差異、歸屬、來源、候選／衝突及回歸|

這是可選階段集合，不要求每集從零走遍。標記授權不包含刪除；已授權的階段持續做到可交付。來源改版讓依賴它的舊交付 stale；重新驗證可沿用的分析也需記錄新依賴。

## 內容取捨（C10）

腳本是內容結構與核對基準，不是逐句刪留清單。腳本外的臨場補充若增加新資訊、說服力、實例、必要限定或自然互動，應保留或只做句內精修；不得只因腳本未寫就整段標刪。需要控制片長時，先處理已被替代的重講、停頓、贅詞、殘句與低價值延伸，再評估仍有內容價值的補充段。

## Premiere 交換

讀實際 XML 的序列、資源、巢狀／多機位、圖形、轉場、變速、tick、音軌角色與空軌。用精確幀率分數、序列起始 TC、DF/NDF、來源 TC；來源時間、序列時間及 SRT 秒數分開。IN/OUT 採 `[in,out)`；顯示最後可用格另命名。混合幀率／變速用明確映射，不以同一格數代替。

粗剪 splitter 只切割標色，須保留時長、順序、完整來源覆蓋、旋轉、其他效果、ticks、非目標軌及資源參照。不支援的轉場／巢狀／變速不得平面化或猜測；保留來源並交待審決策或可支援的 picture-only overlay。精剪改時序須另用可支援的實作，不放寬 splitter 契約。

B-roll 覆蓋依當版主軸配置，不移動口播。檢查序列範圍、無重疊、來源不超出已驗證首選、不擋必要字卡／操作／反應；無聲版不含 B-roll 音訊片段或 audio link。只有覆蓋軌不能改變原主軸音樂狀態。選取全部片段貼回時，提供當版第一及最後片段起點與 TC 格式；不能一律叫使用者貼到零點。

## 驗證及限制

記錄 `structural`、`perceptual`、`premiere_import` 各自為 passed / partial / not_run / failed，附實際工具、範圍與證據。XML 能解析不等於內容、旋轉與資源都保留；結構通過不等於 Premiere 2026 匯入／播放通過。交付檔須與驗證檔 hash 一致，來源 hash 不變。沒有回聽、全片觀看、穩定器測試或 PR 匯入就明記未做。

預設背景作業，不自行操作 Premiere UI。未完成項目保留可接續狀態；不將風格候選或交付結果稱作人工定案。

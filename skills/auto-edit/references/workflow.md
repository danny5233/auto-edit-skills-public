# 開發中的剪輯流程

本文件是流程設計，不是執行器。依需求選擇收件、素材盤點、分類、選鏡、粗剪標記、B-roll 編排、字幕及人工定案學習。

- 收件：記錄當集來源、雜湊、序列幀率、最新人工版本及本次授權階段。
- 分類與選鏡：保留來源映射、不確定性與待確認區間。
- 粗剪標記：以非破壞性 XML 分段與標色保留全部素材和總長。
- B-roll：依主軸語意與可用區間建立可審查的覆蓋軌；不假設引擎支援所有巢狀、速度、轉場或多機位結構。
- 字幕：已有字幕先用；語音辨識需要使用者提供來源与有效授權。
- 定案學習：僅將人工確認的可重用規則寫入對應系列的私人設定；不混用不同集的時間碼或素材。

實際引擎與客戶／系列設定仍需另行實作，不附任何客戶專案路徑或既有交付案例。

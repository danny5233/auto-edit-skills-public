# 自動剪輯流程草案

狀態：draft。尚無可執行的 editflow.py；不能聲稱本 Skill 已能自動完成剪輯。
先依使用者的系列、當集素材、最新人工 XML／SRT 和授權階段建立計畫。
分類、粗剪標記、B-roll 編排與字幕是不同階段；不要用切段標色引擎冒充任意多機位剪輯支援。
只沿用已確認的系列規則，不沿用其他集的影音、逐字稿或時間碼。
參見 [流程規格](references/workflow.md)。

## 版本與個人設定

使用前在本公開倉庫檢查 GitHub 更新；乾淨工作樹只做 fast-forward，保留自行修改的內容。個人 API 授權、客戶詞彙與系列學習存放於自己的私人工作區，不提交到公開倉庫。

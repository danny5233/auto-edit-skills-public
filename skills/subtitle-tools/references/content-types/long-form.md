# 長影片規則

只有工作區或使用者將本次任務指定為 `long_form` 時才讀取本文件。

- 延續共用字幕規則，不建立長影片專用的客戶名詞或講者資料。
- 優先維持完整口語語意與穩定閱讀節奏，避免把同一講者的連續說明切成過多零碎短段。
- 仍依真實停頓、講者切換、完整詞組與閱讀速度重切；長影片不代表可以忽略字數、顯示速度或時間軸規則。
- 過長內容先找自然語意切點，不得為了保留長句而延後字幕、跨講者合併或拆開專有名詞。
- 橫式畫面或較長片長不能單獨決定 `content_type`；仍以使用者指示或來源路徑為準。
- 客戶 profile 若有標記 `content_type: long_form` 的已確認偏好，在不違反品質硬規則的前提下再套用。

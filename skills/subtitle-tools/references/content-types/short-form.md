# 短影片規則

只有工作區或使用者將本次任務指定為 `short_form` 時才讀取本文件。

- 延續共用字幕規則，不建立短影片專用的客戶名詞或講者資料。
- 在真實語音、講者與語意都允許時，偏向較短、較密集的口語節拍；短引導詞、回答、反應、數字重點或轉折可以獨立成段。
- 不得只按固定字數切句。不可拆開專有名詞、固定詞組、否定結構、數字單位或同一講者的必要語意。
- 找不到自然切點時，保留完整語意並按共用規則列為已審視例外，不為了短而刪字或改寫。
- 直式畫面常見於短影片，但直式本身不能決定 `content_type`；仍以使用者指示或來源路徑為準。
- 客戶 profile 若有標記 `content_type: short_form` 的已確認偏好，在不違反品質硬規則的前提下再套用。
